# Kinetix AI

**Tagline:** Your AI personal trainer for perfect form.

## Elevator Pitch

Kinetix is your AI personal trainer. Using your webcam, it analyzes your exercise form in real-time, providing instant visual and spoken feedback to ensure perfect technique and prevent injury.

## About This Project

This project was built in Firebase Studio. The main application logic can be found in `src/app/page.tsx`.
