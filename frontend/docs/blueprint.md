# **App Name**: Kinetix

## Core Features:

- Live Video Feed: Display the user's webcam feed in real-time using a full-screen video element.
- AI Pose Estimation: Overlay a canvas on the video feed to draw skeleton lines based on AI pose estimation.
- Thought Signatures: Display real-time analysis logs ('Thought Signatures') in a collapsible sidebar to show what the AI is processing. The LLM will use the Pose Estimation tool to produce the logs.
- Status Indicator: Implement a clear traffic light system (Green = Good Form, Red = Stop) to provide immediate feedback to the user.

## Style Guidelines:

- Primary color: Deep teal (#008080) to promote a sense of calm focus.
- Background color: Very light grayish-teal (#E0F8F8). This hue evokes a similar feeling as the primary, but keeps a low profile.
- Accent color: Cyan (#00FFFF) to create noticeable highlights and calls to action. Note: avoid overuse of the accent, as this color tends to dominate visually.
- Font: 'Inter' (sans-serif) for both headlines and body text, providing a modern and neutral look. Its clean lines promote easy readability and will minimize distractions, which will help with user focus.
- Use Lucide React icons for a consistent and clean aesthetic throughout the interface.
- Full-screen video feed with a collapsible sidebar on the right for AI analysis logs.
- Subtle transitions and animations for a smooth user experience. Avoid distracting animations.
